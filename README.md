# TaskFlow

Durante minha carreira como testador, desenvolvi um projeto para aplicar conceitos de testes em software utilizando Jira e Zephyr Essential.
A ideia era fazer a gestão das tarefas criando histórias de usuário, casos de teste e fluxos de trabalho com uma visão clara sobre o desenvolvimento e a correção de bugs.

## Ferramentas usadas

- **Jira:** organização de histórias e criação de fluxos de trabalho.
- **Zephyr Essential** – Gerenciamento de Casos de Teste
- **XMind:** um mapa mental para organizar requisitos

## Casos de teste

Criamos 4 casos de teste no Zephyr da seguinte forma:

| Code | Test case |
|---|---|
| TAS-T1 | Criar uma tarefa com dados válidos |
| TAS-T2 | Impedir o cadastro de uma tarefa sem título |
| TAS-T3 | Concluir um caso de teste existente |
| TAS-T4 | Reabrir uma tarefa disponível |

Os testes foram estruturados em termos de objetivos, pré-condições, passos e resultados esperados.

## Fluxos de trabalho

Dois fluxos de trabalho também foram desenvolvidos no Jira:

- **História:** conta a vida de uma funcionalidade desde o backlog até a produção
- **Bug:** é como você gerencia o ciclo de analisar, corrigir e retestar um problema encontrado.

E ambos esses fluxos foram configurados e publicados/testados no Jira.
